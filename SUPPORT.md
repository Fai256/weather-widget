# Support

## Where to get help

| Need | Where |
|---|---|
| Bug report / feature request | [Open a GitHub issue](https://github.com/Fai256/weather-widget/issues/new/choose) |
| Question about using the plugin, or a general Hermes question | [Nous Research Discord](https://discord.com/invite/nousresearch) |
| Hermes Desktop issues | [Hermes Agent repo](https://github.com/NousResearch/hermes-agent) |
| Plugin not loading | See README. Ensure the file is at `desktop-plugins/weather/plugin.js` (exactly) |

GitHub Discussions are not enabled on this repo - use the Discord for open-ended questions.

## Before opening an issue

1. Check the [README](README.md) for install/config steps
2. Reload desktop plugins if the widget is missing: **Ctrl-K** (**⌘K** on macOS) → **Reload desktop plugins** (it normally loads on its own)
3. Hover the status bar chip - the tooltip starts with the build marker (e.g. `v2.0`). Include it in the report
4. Check Hermes Desktop logs (Settings → Developer → Logs) - a plugin that fails to load is recorded there
